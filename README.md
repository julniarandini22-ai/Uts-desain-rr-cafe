## Deskripsi
Website company profile RR Cafe dibangun menggunakan HTML, CSS, dan JavaScript tanpa framework eksternal. Halaman yang tersedia adalah Beranda, Tentang Kami, Produk, dan Kontak. Menu Produk memiliki submenu dropdown Makanan dan Minuman saat hover pada desktop dan dapat dibuka melalui navigasi mobile.

## Struktur
- `index.html` — Beranda
- `about.html` — Sejarah, visi, misi, struktur organisasi
- `produk.html` — Produk makanan dan minuman
- `kontak.html` — Informasi kontak dan form contoh
- `css/style.css` — Desain dan responsivitas
- `js/main.js` — Hamburger menu, submenu mobile, simulasi form

## Menjalankan
Buka `index.html` di browser. Tidak membutuhkan server lokal atau instalasi dependensi.

## Deploy ke GitHub Pages
1. Buat repository publik baru di GitHub.
2. Unggah **isi folder website**, bukan ZIP-nya, ke root repository.
3. Buka **Settings → Pages → Build and deployment**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)` lalu simpan.
5. Tunggu GitHub memberikan alamat website, kemudian masukkan link tersebut di atas.
