## Deskripsi
Website company profile RR Cafe dibuat dengan HTML, CSS, dan JavaScript tanpa framework eksternal. Berisi Beranda, Tentang Kami, Produk makanan & minuman, Kontak; submenu responsif untuk desktop dan mobile.

## Struktur file (semua di root GitHub)
- `index.html` — beranda
- `about.html` — tentang kami, visi & misi
- `produk.html` — makanan dan minuman
- `kontak.html` — informasi kontak dan form simulasi
- `style.css` — desain halaman dan responsivitas
- `main.js` — hamburger menu, submenu mobile, dan form simulasi

## Cara memasang / memperbarui
1. Ekstrak ZIP ini. **Jangan upload ZIP langsung**; GitHub Pages tidak mengekstraknya.
2. Masuk ke repository GitHub di atas → **Add file → Upload files**.
3. Unggah seluruh **7 file** hasil ekstrak sekaligus ke root repository (bukan subfolder), lalu **Commit changes**.
4. GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
5. Buka kembali URL website. Refresh jika masih tampil versi lama.
